# TEa.G3 — قائمة تدقيق القبول

> **مرجع القبول النهائي هو جهاز PlayStation 2 الحقيقي.** نجاح CI أو PCSX2 يثبت جوانب البناء والتشخيص فقط، ولا يثبت توافق الألعاب على الجهاز.
>
> هذه القائمة تصف بنية OPL-only الحالية. لا يُعلن دعم أي محول قبل اختبار اللعبة والقراءة المستمرة والعودة على جهاز فعلي.

## 1. سياسة المحرك الحالية

- [x] OPL هو محرك ألعاب PS2 الوحيد.
- [x] إعدادا `auto` و`opl` يختاران محولات OPL فقط.
- [x] إعداد `motor = neutrino` القديم مرفوض ولا يوجد fallback.
- [x] لا يُبنى أو يُضمّن أو يُشغّل Neutrino EE game ELF.
- [x] تُضمّن وحدات SMB IOP الثلاثة (`smap.irx`, `ministack.irx`, `smb_ioman.irx`) لفهرسة الألعاب فقط؛ OPL ETH هو من يقرأ بيانات اللعبة.
- [x] محولات OPL BDM وETH وHDD وUL موجودة في سياسة الاختيار ومسارات hand-off.
- [x] مصادر MMCE وUDPBD وUDPFS ليست محولات OPL فعالة، وتُحظر.

## 2. أدلة البناء الآلية

- [x] مصدر `TEaG3/OPL` مثبت في submodule `engine/opl`.
- [x] تصحيحات OPL الخاصة بـBDM وETH وHDD وUL تطبق في CI.
- [x] بناء SMB IOP support modules منفصل عن بناء محرك الألعاب؛ لا يُبنى Neutrino EE ELF.
- [x] بيان runtime يتطلب `OPL.ELF` ووحدات SMB الثلاثة فقط.
- [x] فحص manifest يمنع إدراج `neutrino/neutrino.elf`.
- [x] حزمة الإصدار تحتفظ بترخيص OPL وترخيص وحدات SMB كلٌّ على حدة.
- [ ] انتظار نجاح CI النهائي على فرع OPL-only بعد جميع التعديلات الحالية.
- [ ] تحديث مرجع run وcommit وSHA-256 بعد نجاح ذلك البناء.

**تنبيه:** نتائج CI السابقة التي بنت OPL مع Neutrino تخص بنية قديمة، ولا تُعد دليلاً على الحزمة الجديدة OPL-only.

## 3. الهوية وإعادة التسمية

- [ ] يظهر شعار TEa.G3 بوضوح في شاشة البدء وجميع الثيمات.
- [ ] تظهر عبارة TEa.G3 BIOS في شاشة BIOS الخاصة بالثيم الذي يعرضها.
- [ ] لا تظهر أسماء NULD أو ORBIT كعلامة المنتج في الواجهة أو رسائل المستخدم.
- [ ] يظهر اسم المنتج الجديد في إعدادات التحديث ورسائل تثبيت مشغّل FMCB.
- [ ] يبقى الثيم الكلاسيكي متاحاً؛ مفتاحه الداخلي القديم لا يُحذف لمجرد تغيير اسمه المرئي.
- [ ] يعمل إدخال FMCB القديم BOOT/NULD.ELF، وكذلك BOOT/ORBIT.ELF إن كان موجوداً.
- [ ] يُثبّت المشغّل الحالي BOOT/TEa.G3.ELF ويُحدّث المداخل القديمة دون إبطال اختصارات المستخدم.

## 4. العربية واللغات واتجاه النص

- [x] اللغة الافتراضية للتركيب الجديد عربية، واللغة المجهولة تعود إلى العربية.
- [x] واجهة TEa.G3 الأساسية تتحقق آلياً من تطابق مفاتيح النصوص الإنجليزية والعربية.
- [x] تشكيل الحروف العربية والخط والرموز العربية الأساسية مفحوصة آلياً.
- [x] اتجاه المقاطع اللاتينية والأرقام داخل الجمل العربية مشمول باختبارات gfx.c.
- [x] دليل الموقع يوضح أن OPL هو محرك الألعاب الوحيد، وأن إعدادات Neutrino القديمة مرفوضة.
- [ ] افحص بصرياً على جهاز PS2: أرقام IP، امتدادات الملفات، أحجام الألعاب، النسب المئوية، وأسماء الألعاب المختلطة العربية واللاتينية.
- [ ] اختبر تبديل ar/es/en/pt من واجهة الإعدادات، ثم أعد التشغيل وتحقق من حفظ اللغة.

## 5. واجهة IGR والإنجازات

- [x] مصدر واجهة IGR العربية القديم محفوظ في المستودع كمرجع/مصدر واجهة، لكنه ليس محرك ألعاب ولا يُبنى داخل runtime.
- [x] لا توجد قائمة Neutrino داخل اللعبة أو Neutrino achievement agent في حزمة OPL-only.
- [ ] اختبر اختصارات IGR الخاصة بـOPL على جهاز PS2.
- [ ] اختبر عودة OPL إلى TEa.G3 عبر recovery stub.
- [ ] تحقق من أن واجهة الإنجازات تعرض بيانات المكتبة فقط ولا توحي بوجود وكيل إنجازات داخل اللعبة.
- [ ] سجّل رسائل الخطأ الفعلية عند فشل تحميل OPL أو وحدات SMB أو مصدر التخزين.

## 6. محولات التشغيل والصيغ

| المصدر | الصيغة | المسار المتوقع | حالة الاختبار الفعلي |
|---|---|---|---|
| USB / BDM / MX4SIO / iLink | ISO | OPL BDM | بانتظار PS2 |
| USB / BDM | ZSO | OPL BDM | بانتظار PS2 |
| SMB مهيأ | ISO / ZSO | OPL ETH | بانتظار PS2 |
| APA / HD Loader HDD | ISO | OPL HDD mini-launch | بانتظار PS2 |
| APA / HD Loader HDD | ZSO | مرفوض | متوقع الرفض |
| USB | USBExtreme UL | OPL UL | بانتظار PS2 |
| MMCE / UDPBD / UDPFS | ISO / ZSO | مرفوض؛ لا يوجد محول OPL | متوقع الرفض |

- [x] اختبار parser الخاص بـUL يتحقق من السجلات وأجزاء ul.* المفقودة والحدود.
- [x] اختبار host لـZSO يتحقق من فك الترميز والقراءة والحدود.
- [x] اختبار قرار المحرك يتحقق من OPL BDM وETH وHDD وUL، ويرفض Neutrino والمصادر غير المدعومة.
- [ ] اختبر USB ISO وZSO على جهاز فعلي، مع قراءة مستمرة لمدة 15 دقيقة على الأقل.
- [ ] اختبر UL مع ul.cfg وجميع الأجزاء المتتابعة.
- [ ] اختبر SMB ISO وZSO مع بيانات دخول صحيحة وخاطئة وفصل الكابل وإعادة تشغيل الخادم.
- [ ] اختبر APA/HDL ISO وتحقق من قطاع البداية والحجم الكلي وقسم OPL الموجود مسبقاً.
- [ ] تأكد أن OPL لا ينشئ أو يهيئ أقسام HDD تلقائياً.
- [ ] اختبر أن `motor = neutrino` يُرفض وأن لا يوجد أي Neutrino ELF في `tea_g3/runtime/`.

## 7. الشبكة وSMB

- [x] يقرأ TEa.G3 فهرس `TEAG3.GAMES` من مشاركة SMB.
- [x] وحدات SMB IOP المضمّنة منفصلة عن محرك الألعاب.
- [x] يمرر TEa.G3 إعدادات IPv4 والخادم والمشاركة وبيانات الدخول إلى OPL ETH.
- [ ] اختبر SMB على PS2 حقيقي، بما في ذلك تسجيل الدخول والقراءة المستمرة وفصل الشبكة.
- [ ] تأكد من أن كلمة مرور SMB لا تظهر في السجلات أو لقطات الشاشة أو الحزم العامة.
- [ ] اختبر رفض إعداد IPv4 أو share غير صالح دون تشغيل محرك بديل.

- [ ] اختبر ترحيل مجلدات `nuld/` و`orbit/` إلى `tea_g3/` مع الاحتفاظ بنسخة احتياطية.
