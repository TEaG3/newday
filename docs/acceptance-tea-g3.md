# TEa.G3 — قائمة تدقيق القبول

> **مرجع القبول النهائي هو جهاز PlayStation 2 الحقيقي.** نجاح CI أو PCSX2 يثبتان جوانب البناء والتشخيص فقط، ولا يثبتان توافق الألعاب على الجهاز.
>
> راجع أيضاً [بوابات الجودة ودروس الانحدار](quality-gates.md): لا تُستخدم نتائج PCSX2 لإثبات الأداء، ولا تُغلق اختبارات العتاد من سجلات البناء وحدها.

## 1. الأدلة الآلية الحالية

- [x] بناء OPL من المصدر المثبّت في workflow، مع جلب اعتماد lwNBD وتطبيق تصحيحات USBExtreme UL وSMB/ETH وAPA/HDL.
- [x] بناء وحدات OPL الخاصة بمحاكاة يد التحكم USB وBluetooth مع `PADEMU=1` (بناء فقط؛ الاقتران الفعلي يحتاج جهازاً).
- [x] اختبار ZSO على المضيف.
- [x] دمج OPL وNeutrino داخل نقطة تشغيل واحدة TEa.G3.ELF.
- [x] إنشاء حزمة اختبار موحدة تحتوي على المشغّل وOPL وNeutrino والوحدات المطلوبة (76 ملفاً في بيان runtime).
- [x] اجتياز 37 اختبار مضيف، واختبارات ZSO الخام/المضغوطة والحدود وأخطاء I/O والتخصيص، واختبار فهرسة snapshot/diff وبوابة التطبيق المتزامن.
- [x] التحقق من الخط العربي: 509 محارف، أطلس 512×384، ضمن 12 صفحة PSMT4.
- [x] التحقق من مفاتيح واجهة المشغّل: 161 سلسلة إنجليزية و161 عربية، دون سلاسل عربية مفقودة أو زائدة.
- [x] اختبارات تشكيل واتجاه العربية، بما فيها IP 192.168.1.5 وUSB OK.
- [x] اختبارات FMCB وVMC وZSO وUL واختيار المحرك وبقية وحدات المضيف.
- [x] فحص الثيمات واسم TEa.G3 في شاشة البدء.
- [x] بناء TEa.G3.ELF بحجم يقارب 9.3 MiB في CI.

**مرجع الأدلة الآلية الأحدث:** GitHub Actions run [#687](https://github.com/TEaG3/newday/actions/runs/45659251010)، بتاريخ 25 نوفمبر 2026، على commit `0e4c5bad82aaffd41b747745b014eb2951e48693`. نجحت وظائف ZSO host، وبناء OPL، وبناء Neutrino، وتجميع ELF والحزمة. حزمة الاختبار الموحدة: [artifact 15043408874](https://github.com/TEaG3/newday/actions/runs/45659251010/artifacts/15043408874)، SHA-256: `01e18288cf0a0ec27ad740f5b691b0ad749936e8386ec57f0a67294c61f844dd`. هذه العلامات تخص نتائج CI لهذا الـ commit فقط؛ ولا تثبت تشغيل الألعاب على جهاز PS2.

## 2. الهوية وإعادة التسمية

- [ ] يظهر شعار TEa.G3 بوضوح في شاشة البدء وجميع الثيمات.
- [ ] تظهر عبارة TEa.G3 BIOS في شاشة BIOS الخاصة بالثيم الذي يعرضها.
- [ ] لا تظهر أسماء NULD أو ORBIT كعلامة المنتج في الواجهة أو رسائل المستخدم.
- [ ] يظهر اسم المنتج الجديد في إعدادات التحديث ورسائل تثبيت مشغّل FMCB.
- [ ] يبقى الثيم الكلاسيكي متاحاً؛ مفتاحه الداخلي القديم لا يُحذف لمجرد تغيير اسمه المرئي.
- [ ] يعمل إدخال FMCB القديم BOOT/NULD.ELF، وكذلك BOOT/ORBIT.ELF إن كان موجوداً.
- [ ] يُثبّت المشغّل الحالي BOOT/TEa.G3.ELF ويُحدّث المداخل القديمة دون إبطال اختصارات المستخدم.

## 3. العربية واللغات واتجاه النص

- [x] اللغة الافتراضية للتركيب الجديد عربية، واللغة المجهولة تعود إلى العربية.
- [x] واجهة TEa.G3 الأساسية تتحقق آلياً من تطابق مفاتيح النصوص الإنجليزية والعربية؛ هذا الفحص لا يدّعي اكتمال جميع ترجمات OPL.
- [x] تشكيل الحروف العربية والخط والرموز العربية الأساسية مفحوصة آلياً.
- [x] قائمة Neutrino داخل اللعبة تعرض أوامر عربية: إعادة تشغيل، إيقاف التشغيل، إلغاء.
- [x] إشعار الإنجاز داخل قائمة Neutrino له مورد عربي.
- [x] اتجاه المقاطع اللاتينية والأرقام داخل الجمل العربية مشمول باختبارات مضمنة في gfx.c.
- [ ] افحص بصرياً على جهاز PS2: أرقام IP، امتدادات الملفات، أحجام الألعاب، النسب المئوية، وأسماء الألعاب المختلطة العربية واللاتينية.
- [ ] اختبر تبديل ar/es/en/pt من واجهة الإعدادات، ثم أعد التشغيل وتحقق من حفظ اللغة.

**ملاحظة تنفيذية:** لا تضف bidi_helpers.c المقترح في الملف النصي حالياً؛ المشروع يملك بالفعل محلّل اتجاه ومشكّل حروف داخل gfx.c واختبارات له. إضافة علامات LRM قبل التأكد من دعمها في محلّل UTF-8 والخط قد تُدخل محارف غير مرسومة أو تغيّر ترتيب النص.

## 4. قائمة الإيقاف داخل اللعبة والرسائل

- [x] أوامر IGR الثلاثة الحالية مترجمة إلى العربية.
- [x] إشعار الإنجاز العربي مولّد من الخط المثبّت.
- [ ] اختبر ظهور القائمة داخل لعبة PS2 فعلية ثم نفّذ restart وpower off وcancel.
- [ ] تحقق من أن لوحة التحكم تستجيب في كل خيار.
- [ ] سجّل أي رسالة خطأ فعلية تظهر بالإنجليزية؛ لا تضف ترجمات تخمينية لعبارات لا يستخدمها الكود.
- [ ] اختبر رسائل تعذّر تحميل المحركات والاتصال وقراءة التخزين والحفظ كما تنتجها الحالات الحقيقية.

## 5. محركات التشغيل والصيغ

- [x] بناء OPL المضمّن ينجح من المصدر المثبّت.
- [x] مسار USBExtreme UL إلى OPL لديه اختبار parser وchecks في CI.
- [x] يوجد اختبار آلي لجدول اختيار المحرك.
- [ ] USB ISO: جرّب motor = auto وتأكد أن Neutrino يفتح اللعبة.
- [ ] USB ZSO: جرّب motor = auto وتحقق من العنوان والرقم التسلسلي والقراءة داخل اللعبة.
- [ ] USBExtreme UL: جرّب ul.cfg وكل أجزاء ul.* مع OPL على جهاز حقيقي.
- [ ] USB ISO/ZSO: جرّب motor = opl كمسار OPL اليدوي.
- [ ] PS1 POPStarter: اختبر لعبة متوافقة من مجلد POPS.
- [ ] اختبر العودة من اللعبة إلى TEa.G3 وقائمة IGR.
- [ ] اختبر HDD/HDLoader وMX4SIO وiLink وSMB وMMCE كل مصدر على حدة، ولا تعتبر وجود ملفات أو وحدات تشغيل ضمن Neutrino دليلاً على اكتمال محولات OPL لهذه المصادر.
- [ ] لا تعلن دعم أي صيغة أو مصدر إضافي قبل اختبار بدء اللعبة والقراءة المستمرة والاستقرار.

## 6. الذاكرة والتوافق والترقية

- [ ] تُعاد الاستفادة من VMC/NULD.bin وVMC/ORBIT.bin الموجودة دون فقد الحفظات.
- [ ] VMC لكل لعبة تعمل وتُحفظ على المصدر الصحيح.
- [ ] بطاقة الذاكرة الفيزيائية تعمل.
- [ ] ترحيل مجلدات nuld/ وorbit/ إلى tea_g3/ يحفظ الإعدادات والأغلفة والبيانات المتاحة.
- [ ] لا تحذف ملفات المصدر القديمة حتى تُراجع نتيجة الترحيل يدوياً.
- [ ] افحص الإقلاع من FMCB القديم بعد تحديث ملفات البطاقة.

## 9. تجربة تقليل حجم ELF — اختيارية وغير مفعّلة

- [x] بقي Makefile الأساسي دون فرض NEWLIB_NANO أو EE_COMPACT_EXECUTABLE؛ لا توجد مقارنة موثقة تثبت سلامة تفعيلهما لهذا المشروع.
- [ ] إن أُجريت التجربة، فلتكن في فرع أو workflow منفصل مع الاحتفاظ ببناء baseline.
- [ ] قارن الحجم بعد strip، وافحص رموز الربط، واختبر تنسيقات printf وTLS وRetroAchievements وبقية الوظائف.
- [ ] لا تدمج خيار تقليل الحجم إلا بعد بناء كامل ناجح واختبارات وظيفية على الجهاز.
