TEa.G3 — Installation

1. Format a USB drive as FAT32.
2. Copy TEa.G3.ELF to the USB root.
3. Put PS2 ISO/ZSO images in DVD/ or CD/ as appropriate.
4. Put USBExtreme UL files, ul.cfg and all ul.* parts in the USB root.
5. Launch TEa.G3 through FreeMcBoot or a compatible ELF launcher.

OPL is the only PS2 game engine and is embedded in TEa.G3. Do not install or copy a second runtime.

Video output:
- The launcher starts in interlaced 480i (NTSC) or 576i (PAL), the broadly compatible mode for composite AV (yellow/red/white) and many Component/HDMI displays.
- Press L2+R2 to toggle between interlaced mode and 720p.
- Use 720p only when the display/adapter supports it.
- Output depends on the PS2 cable, the console RGB/YPbPr setting and the TV input; the software cannot guarantee every mode on every connector simultaneously.

Game sources:
- USB ISO/ZSO and USBExtreme UL use their OPL adapters.
- HDD, HD Loader, MX4SIO and iLink require the matching OPL adapter and hardware validation.
- SMB, UDPBD, UDPFS game streaming and MMCE game-source launching are disabled in this build; they are not redirected to another engine.
- PS1 uses POPStarter; ELF applications use the application loader.

A successful CI build does not prove gameplay. Validate boot and sustained reads on real PS2 hardware before relying on a backend.
