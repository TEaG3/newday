TEa.G3 — USB Drive Setup Guide (English)
==========================================

1. USB drive layout
-------------------
Extract the USB-Template.zip archive and copy its folders directly to the USB
root. DVD, CD, POPS and APPS must sit beside TEa.G3.ELF, not inside another
enclosing folder.

USB:/
├── TEa.G3.ELF
├── DVD/
├── CD/
├── POPS/
├── APPS/
├── ul.cfg          (only when using USBExtreme/UL games)
└── ul.*            (the game's split parts, if present)

The folder template contains neither TEa.G3.ELF nor games. Copy the actual
launcher ELF from a TEa.G3 release to the USB root.

2. Where to put games
---------------------
- DVD/: PS2 DVD games in ISO or ZSO format.
- CD/: PS2 CD-based games.
- POPS/: PS1 game files compatible with POPStarter, prepared using the file
  format and naming required by the POPStarter setup in use.
- APPS/: homebrew applications in ELF format.

Do not place ISO files directly in the USB root. Do not put DVD games in CD,
or CD games in DVD.

3. USBExtreme / UL games
------------------------
UL games are not ordinary ISO files. Keep ul.cfg and every associated ul.*
part in the USB root, using their original filenames. Do not rename the parts
or move them into DVD or CD.

4. Launcher and game engine
----------------------------
OPL is the only PS2 game engine in this build. It is embedded in
TEa.G3.ELF and extracted automatically on first boot. Do not copy a separate
Neutrino runtime or expect Neutrino fallback.

The launcher currently wires USB/BDM ISO and ZSO through OPL BDM, and
USBExtreme UL through OPL's UL direct-boot path. SMB, UDPBD, UDPFS, MMCE and
APA/HD Loader launch routes are disabled until their OPL adapters are wired
and validated. A listed game is not proof that its source is launchable.

5. USB file system
------------------
Use FAT32. If a game image is larger than FAT32's 4 GB file-size limit, use
exFAT only if your TEa.G3 build, console setup and storage path support it.
Do not manually split an ISO or rename its extension to work around the limit.

6. First boot
-------------
Start TEa.G3.ELF from uLaunchELF or FreeMcBoot. On first boot, the launcher
creates tea_g3/runtime/ and extracts the embedded OPL runtime. Do not unplug
the USB drive while this setup is running.

7. Important notes
------------------
- Do not delete tea_g3/runtime after TEa.G3 creates it; it contains the
  extracted OPL runtime.
- Keep UL filenames and split parts unchanged.
- A game appearing in the list does not guarantee that every title will boot.
  Compatibility can depend on the game, console configuration and storage path.
- Successful builds and automated tests do not replace testing on real PS2
  hardware.
