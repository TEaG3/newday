# Installing TEa.G3

## 1. Requirements
- A PlayStation 2 that can run homebrew through FreeMcBoot or uLaunchELF.
- FAT32 or exFAT USB storage.
- For SMB: wired Ethernet and a compatible network adapter.

## 2. Install
1. Copy `TEa.G3.ELF` and your game folders to the USB root.
2. Put DVD ISO/ZSO images in `DVD/` and CD images in `CD/`.
3. Keep USBExtreme UL files (`ul.cfg` and every `ul.*` part) in the USB root, not inside `DVD/`.
4. Start `mass0:/TEa.G3.ELF` from uLaunchELF or add it to FreeMcBoot.

**Do not copy a separate OPL.ELF or Neutrino folder.** TEa.G3.ELF embeds OPL and the SMB support IOP modules and installs them under `tea_g3/runtime/`. OPL is the only PS2 game engine; Neutrino is not built, launched or used as a fallback.

## 3. Supported launch sources

| Source | Formats | Engine |
|---|---|---|
| USB / MX4SIO / iLink / BDM | ISO and ZSO | OPL BDM |
| Configured SMB share | ISO and ZSO | OPL ETH |
| Internal APA / HD Loader HDD | ISO only | OPL HDD |
| USBExtreme UL on USB | UL | OPL UL |
| MMCE / UDPBD / UDPFS | — | Disabled; no OPL adapter |

Both `auto` and `opl` select OPL only. The legacy `motor = neutrino` setting is rejected and never starts another engine.

## 4. SMB / ETH setup
1. Set a static PS2 IPv4 address in `[red]` in `tea_g3/config.ini`.
2. Set the SMB server, share, user and password in `[smb]`.
3. Place the `TEAG3.GAMES` index file in the share with valid game paths.
4. Enable SMB in the source selector. OPL ETH reads game data; the embedded SMB modules are used only for catalog access.

The SMB password is stored as plain text in `tea_g3/config.ini`. Keep this file private.

## 5. OPL settings
Legacy TEa.G3 video, compatibility and VMC values are retained for configuration migration but are not passed to OPL. Configure video, compatibility and VMC inside OPL. Use OPL's own IGR controls; the former Neutrino in-game menu is not part of this build.

## 6. Test status
Passing CI and building the ELF do not prove gameplay on a real console. USB/BDM, SMB/ETH, APA/HDL and UL require physical PS2 testing, including sustained reads and return-to-launcher behavior. ZSO is not supported by the APA/HDL mini-launch path.

## 7. Upgrading
Keep `tea_g3/` and your game files. The updater migrates legacy `orbit/` or `nuld/` data to `tea_g3/` when needed and preserves old FreeMcBoot entry points.
